## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code recommended)
- Optional: Node.js for local development server

### Installation

```bash
# Clone the repository
git clone https://github.com/manuelmatsinhe/portfolio-1.0.git

# Navigate to project directory
cd portfolio-1.0

# Open in browser (Option 1: Direct)
open index.html

# Or run a local server (Option 2: Better for development)
python -m http.server 8000
# Visit http://localhost:8000
```

## 🎨 Customization

### Colors & Theme
Edit `css/styles.css` to customize:
```css
:root {
  --primary-color: #0066ff;
  --secondary-color: #00d4ff;
  --background: #0f0f1e;
  --text: #ffffff;
}
```

### Content
Update `index.html` with your:
- Name & bio
- Project portfolio
- Skills & experience
- Contact information

### Interactive Features
Modify `js/main.js` to add:
- Smooth scrolling
- Modal dialogs
- Form validation
- Analytics tracking
